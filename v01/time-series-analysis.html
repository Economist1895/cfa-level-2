Time-Series Analysis

In 30 seconds

  • Trend models: linear for constant amount growth, log-linear for constant rate growth. If DW shows serially correlated errors, move to an AR model.
  • AR models need covariance stationarity: constant, finite mean, variance and autocovariances. Test the fit with residual autocorrelations (t = ρ / (1/√T)), not DW.
  • Mean-reverting level = b0​/(1−b1​). Multi-period forecasts use the chain rule. Compare models on out-of-sample RMSE.
  • Random walk = unit root (b1​=1) → not stationary. Test with Dickey–Fuller; fix by first-differencing.
  • Seasonality → add a seasonal lag. Squared residuals depend on past squared residuals → ARCH. Two series with unit roots → need cointegration.

01Trend models

F1

Linear trend

yt​=b0​+b1​t+εt​

Grows by a constant amount b1​ per period. Forecast: y^​t​=b^0​+b^1​t, where t is the period number (count from the first observation).

F2

Log-linear trend

lnyt​=b0​+b1​t+εt​y^​t​=eb^0​+b^1​t​

Grows at a constant rate (exponential growth). Remember to take the antilog for the forecast level.

Testing trend models: Durbin–Watson

  • DW ≈ 2 → no serial correlation. DW < dl​ → reject "no positive serial correlation". DW well above 2 → negative serial correlation.
  • Serially correlated trend residuals (very common) → the trend model is inadequate. SEs are biased, so use an AR model instead.
  • Any series well described by a trend is not covariance stationary.

02AR models & covariance stationarity

F3

AR(p) model

xt​=b0​+b1​xt−1​+⋯+bp​xt−p​+εt​

The X's are lagged values of the series itself. Serially correlated errors make AR coefficients inconsistent (not just their SEs).

Covariance stationary: all three must hold

  • Constant, finite mean in all periods.
  • Constant, finite variance in all periods.
  • Constant, finite covariance with its own lags (depends only on the lag, not on t).
  • Not stationary → AR estimates are spurious: b1​ is biased and tests are invalid. Trends, seasonality and random walks all break stationarity.
  • Stationarity in the past doesn't guarantee it in the future.
F4

Testing AR fit: residual autocorrelations

t=1/T​ρ^​ε,k​​,df=T−(p+1)

standard error of each residual autocorrelation (T = observations)

Steps: estimate AR(1) → compute residual autocorrelations → t-test each lag. Any significant → model misspecified, so try AR(2), AR(3)… until none are significant. DW is invalid when a lagged Y is a regressor.

03Mean reversion, forecasting & RMSE

F5

Mean-reverting level, AR(1)

x^=1−b1​b0​​

Current x above it → forecast falls; below → rises. Every covariance-stationary series has a finite mean-reverting level (∣b1​∣<1). If b1​<0, the denominator is 1+∣b1​∣.

F6

Chain rule of forecasting

x^t+1​x^t+2​​=b^0​+b^1​xt​=b^0​+b^1​x^t+1​​

Feed each forecast into the next. Multi-period forecasts are more uncertain than one-period forecasts. AR(2): x^t+1​=b0​+b1​xt​+b2​xt−1​. Watch which observation is the latest.

F7

Root mean squared error

RMSE=n1​i=1∑n​(actuali​−forecasti​)2​

Lower = more accurate. Judge on out-of-sample errors (periods not used to estimate the model). In-sample errors are just the residuals.

💡
Coefficient instability: estimates and even the best model order (AR(1) vs AR(2)) change with the sample period. Don't mix regimes (fixed vs floating FX, different central-bank policy). A longer sample helps only if the series stays stationary. Plot the data first.

04Random walks & unit roots

F8

Random walk (with drift)

xt​=b0​+xt−1​+εt​

AR(1) with b1​=1 (no drift: b0​=0). Best forecast of xt​ = xt−1​ (+ drift). Mean-reverting level is b0​/0: undefined. Variance (t−1)σ2 → unbounded. So it is not covariance stationary.

F9

First differencing

yt​=xt​−xt−1​=εt​

The differenced random walk is an AR(1) with b0​=b1​=0: stationary, mean-reverting level 0. If the regression on Δx shows an insignificant intercept and slope and no residual autocorrelation, the original series is a random walk.

F10

Dickey–Fuller unit-root test

xt​−xt−1​=b0​+g1​xt−1​+εt​g1​=b1​−1​

H0​: g1​=0 (unit root, nonstationary). Ha​: g1​<0 (stationary). Use the DF critical values (larger in magnitude than the usual t). Only the dependent variable and the slope change; the regressor is still xt−1​.

  • A plain t-test of b1​=1 is invalid: under a unit root the t-stat doesn't follow a t-distribution.
  • ∣b1​∣>1 = explosive root. All random walks, with or without drift, have unit roots.
  • Autocorrelations that decay slowly hint at nonstationarity, but DF is the definitive test.

05Moving-average & ARMA models

F11

n-period moving average (smoothing)

nxt​+xt−1​+⋯+xt−(n−1)​​

Equal weights; smooths out noise. It is not the same thing as an MA(q) model.

F12

MA(q) model

xt​=εt​+θ1​εt−1​+⋯+θq​εt−q​

Memory of q periods: the first q autocorrelations ≠ 0, then they drop to 0 abruptly.

06Seasonality

  • Detect: a significant residual autocorrelation at the seasonal lag (lag 4 for quarterly data, lag 12 for monthly).
  • Fix: add the seasonal lag as an extra regressor, then re-test the residuals.
F13

AR(1) with a seasonal lag (quarterly)

xt​=b0​+b1​xt−1​+b2​xt−4​+εt​x^t+1​=b^0​+b^1​xt​+b^2​xt−3​​

Often applied to Δln(sales): forecast the log change, add it to the last log level, then take the antilog.

07ARCH

F14

ARCH(1) test & variance forecast

ε^t2​=a0​+a1​ε^t−12​+ut​σ^t+12​=a^0​+a^1​ε^t2​​

Regress squared residuals on lagged squared residuals. a1​ significant → ARCH(1): error variance depends on the previous error. SEs are invalid, so correct with generalised least squares. A bonus: you can forecast next-period variance.

08Regressions with two time series

Unit root? (DF on each series)Linear regression?
NeitherOK
Only one of the twoNot valid
Both, not cointegratedNot valid (spurious)
Both, cointegratedOK (long-term relation)
  • Cointegrated = a long-term economic link (common trend), so the series don't drift apart without bound.
  • Engle–Granger test: regress y on x, then run a DF test on the residuals using Engle–Granger critical values. H0​: residual has a unit root = no cointegration. Reject → cointegrated.
  • A cointegrated regression captures the long-run relation, not necessarily the short-run one (error-correction models).

09Model-building steps

  • 1. Plot the series. Is it stationary? Look for a trend, seasonality or a regime shift.
  • 2. No seasonality or shift: fit a linear or log-linear trend, then run DW on the residuals. No serial correlation → use the trend model.
  • 3. Make it stationary: linear trend → first-difference; exponential trend → log, then difference; shift → separate models before and after; seasonality → seasonal lags.
  • 4. Fit AR(1), test residual autocorrelations, and increase the order until none are significant.
  • 5. Check seasonality, then ARCH.
  • 6. Test out-of-sample performance (RMSE).

10Exam traps

⚠️
  • Trend forecast: get t right (first month out of sample = n + 1). For log-linear, exponentiate the result.
  • DW can't be used when a lagged dependent variable is a regressor. Use t = residual autocorrelation × √T.
  • b0​=0 alone does not make a series non-stationary. Only b1​=1 (a unit root) does.
  • Mean-reverting level with a negative slope: b0​/(1−b1​) with b1​=−0.232 gives a denominator of 1.232.
  • Current value below the mean-reverting level → the model predicts a rise.
  • DF regression: the dependent variable becomes xt​−xt−1​ and the slope becomes b1​−1. The independent variable is unchanged.
  • A significant 4th-lag residual autocorrelation in quarterly data → seasonality, so the model is misspecified.
  • Both series have unit roots and are cointegrated → regression valid (coefficients and SEs consistent). Only one has a unit root → invalid.
  • Exponential trend + serially correlated residuals → log, difference, then fit an AR model.
  • Long-horizon forecasts can be nonsensical. A longer sample risks mixing regimes.
