Quantitative Methods

Evaluating Regression Model Fit and Interpreting Model Results

In 30 seconds

  • R² never falls when you add X's, so it overstates fit. Use adjusted R², which rises only if the new variable's |t| > 1.
  • AIC and BIC compare models with the same Y: lower is better. AIC → prediction; BIC → best fit (penalises extra variables more).
  • Single coefficient → t-test. A group of coefficients → joint F-test (restricted vs unrestricted SSE).
  • Whole model → F = MSR / MSE with k and n−k−1 df.
  • Forecast: intercept + every slope × X, including insignificant X's. Forecast intervals widen when the X's are themselves forecasts.

01R² and adjusted R²

F1

Coefficient of determination

R2=SSTSSR​=1−SSTSSE​
SSR
regression (explained) SS: ∑(Y^i​−Yˉ)2
SSE
error (residual) SS: ∑(Yi​−Y^i​)2
SST
total SS = SSR + SSE

Problems in multiple regression: never falls as X's are added · says nothing about coefficient significance · says nothing about bias · a good model can have low R² and an overfit model high R².

F2

Adjusted R²

Rˉ2​=1−SST/(n−1)SSE/(n−k−1)​=1−n−k−1n−1​(1−R2)​
k
number of independent variables (slopes), not counting the intercept

Adding a variable: |t| > 1 → Rˉ2 rises; |t| < 1 → falls. A low bar: |t| = 1 is not significant at 5%.

  • With k≥1: Rˉ2<R2. Rˉ2 can be negative; R² can't.
  • Rˉ2 has no "% of variation explained" interpretation.
  • Neither R² nor Rˉ2 tests the significance of the fit. That needs the F-test.

02AIC & BIC

F3

Akaike's information criterion

AIC=nln(nSSE​)+2(k+1)

Preferred for prediction. 2(k+1) is the penalty for extra parameters.

F4

Schwarz's Bayesian criterion

BIC=nln(nSSE​)+ln(n)(k+1)

Preferred for goodness of fit (parsimony). lnn>2 once n≥8, so BIC penalises complexity more and picks smaller models.

💡
Only relative values matter, and only across models with the same Y. A model with all X's typically has the highest R² but can rank badly on Rˉ2, AIC and BIC.

03Hypothesis tests on coefficients

F5

t-test on one coefficient

t=sb^j​​b^j​−Bj​​,df=n−k−1

Same as simple regression. Software tests against Bj​=0. For any other Bj​ (e.g. 1), recompute t or check whether Bj​ lies inside the confidence interval.

F6

Joint F-test (nested models)

F=SSEU​/(n−k−1)(SSER​−SSEU​)/q​
R / U
restricted (fewer X's) / unrestricted (all X's) model
q
number of restrictions = X's dropped
k
slopes in the unrestricted model

H0​: the q dropped slopes all = 0. Df: q and n−k−1. One-tailed (right). Reject → the group adds explanatory power. Fail to reject → prefer the more parsimonious restricted model.

F7

General linear F-test (whole model)

F=MSEMSR​=SSE/(n−k−1)SSR/k​​

H0​: b1​=b2​=⋯=bk​=0; Ha​: at least one =0. Df: k and n−k−1. Right-tailed.

💡
Why not just use individual t-tests? Correlated X's share explanatory power, so each can look insignificant alone while the group matters.

05Forecasting

F8

Predicted value

Y^f​=b^0​+j=1∑k​b^j​Xjf​

Include the intercept and every X in the estimated model, even insignificant ones: the slopes were estimated jointly, so they reflect correlations among the X's.

  • Model error: the residual ε, always present.
  • Sampling error: from forecasting the X's themselves (out-of-sample).
  • Together they make the standard error of the forecast > the standard error of the regression, so the prediction interval is wider.

06Exam traps

⚠️
  • Adding a variable with |t| < 1 (e.g. t = −0.28): R² stays the same or rises, but adjusted R² falls because the variable adds no explanatory power.
  • Best fit → lowest BIC. Prediction → lowest AIC. Don't pick the model with the highest R².
  • Joint F: the restricted model is the one without the tested variables. Use the unrestricted model's n−k−1 in the denominator.
  • q = number of variables dropped, not the number of variables left.
  • Forecast: don't drop insignificant X's or forget the intercept. Watch the signs of negative X's.
  • A slope can be insignificant individually while the group is jointly significant (and vice versa).
  • Testing H0​:bj​=1: the software's t-stat (vs 0) is not the answer. Recompute it.
  • All F-tests here are one-tailed, right side.
