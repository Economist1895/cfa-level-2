Machine Learning

In 30 seconds

  • Supervised = labelled data (X's + target Y): regression if Y is continuous, classification if Y is categorical or ordinal. Unsupervised = no labels: dimension reduction (PCA) and clustering.
  • Overfitting = low bias, high variance: great in-sample, poor out-of-sample. Fight it with regularisation (less complexity) and cross-validation.
  • Supervised algorithms: LASSO, SVM, KNN, CART, ensembles and random forests. Unsupervised: PCA, k-means, hierarchical clustering.
  • Neural nets / deep learning handle highly non-linear, complex problems. Reinforcement learning = an agent maximising reward by trial and error.

02Generalisation & overfitting

  • Training sample (fit) → validation sample (tune, choose complexity) → test sample (final out-of-sample check). Training + validation = in-sample.
  • Underfit: misses the pattern. Overfit: learns the noise ("perfect hindsight, no foresight"). Causes: noisy data and too much complexity.
F1

Out-of-sample error decomposition

Eout​=bias+variance+base error
Bias
poor fit to the training data → underfitting, high in-sample error
Variance
results swing with new data → overfitting, high out-of-sample error
Base
irreducible randomness in the data

As complexity ↑: bias ↓, variance ↑. The optimum is where total error bottoms out (the fitting curve). Linear models lean to bias; non-linear models lean to variance.

Learning curve (accuracy vs training size)Diagnosis
Curves converge but below the desired accuracyHigh bias (underfit). More data won't help.
Training and validation curves don't convergeHigh variance (overfit)
Converge near the desired accuracyGood fit

Two ways to prevent overfitting

  • 1. Limit complexity (Occam's razor): fewer features, an overfitting penalty (regularisation).
  • 2. Cross-validation: estimate out-of-sample error from validation samples.
  • k-fold CV: shuffle, split into k parts (k = 5 or 10), train on k − 1, validate on 1, repeat k times, average the errors → estimate of Eout​. Can't be used on time series.

03Supervised algorithms

F2

LASSO (penalised regression)

mini=1∑n​(Yi​−Y^i​)2+λk=1∑K​∣b^k​∣

A feature stays only if it cuts SSE by more than it adds to the penalty, so LASSO does feature selection. λ = 0 → plain OLS (no regularisation). Larger λ → more parsimonious. The penalty applies only while training. Good with many correlated features.

  • SVM: linear classifier finding the hyperplane with the maximum margin between two classes. Soft margin penalises misclassified training points; non-linear SVM is more complex and more prone to overfitting. Suits small-to-medium, high-dimensional data (bankruptcy, text sentiment) and is robust to outliers and correlated features.
  • KNN: classify a new point by majority vote of its k nearest neighbours. Non-parametric. Hard parts: choosing the distance metric and k (too small → noisy and outlier-sensitive; too large → dilutes "nearness"; even k → ties). Sensitive to irrelevant or correlated features, so it works best with few features.
  • CART: binary tree (root → decision nodes → terminal nodes); each node is a feature + cutoff chosen to minimise error. Classification tree → majority class; regression tree → mean of the terminal node. Prone to overfitting, so regularise with max depth, min node size or pruning. Interpretable (visual), with no k or distance metric to choose.

Ensembles

  • Ensemble learning combines many models → usually more accurate and more stable than the best single model (noise averages out).
  • Voting classifier (heterogeneous learners): majority vote across e.g. SVM, KNN and CART. More models help only up to a point.
  • Bagging (homogeneous): same algorithm on n bootstrap samples (drawn with replacement), then vote or average → more stable, less overfitting.
  • Random forest: many CARTs on bagged data, each split using a random subset of features. Lower variance and overfitting, better signal-to-noise, but a black box.

04Unsupervised algorithms

  • PCA: turns many correlated features into a few uncorrelated principal components. Eigenvectors define the components; eigenvalues give the share of variance each explains. PC1 explains the most variance and minimises projection error. A scree plot shows how many to keep (often enough for 85–95% of variance). Drawback: the components are hard to interpret. Typically used before fitting another model to cut overfitting and the curse of dimensionality.
  • Clustering groups similar observations: high cohesion within a cluster, high separation between clusters. Distance is usually Euclidean (or correlation).
  • k-means: fix k (a hyperparameter), place random centroids, assign each point to its nearest centroid, recompute the centroids (means), and repeat until no point moves. The result minimises within-cluster distance and maximises between-cluster distance. k must be chosen in advance.
  • Hierarchical: no need to set k. Agglomerative (bottom-up): each point starts as its own cluster and the two closest merge. Divisive (top-down): one cluster splits repeatedly. In a dendrogram, arch height = distance, so shorter dendrites mean more similar.
💡
Clustering uses: find peer groups beyond standard industry codes, and improve diversification (hold stocks from different clusters).

05Neural networks, deep learning & RL

  • Layers: input (one node per feature) → hidden → output. The layer and node counts are hyperparameters.
  • Each hidden node has a summation operator (weighted sum = total net input) and an activation function (non-linear, e.g. sigmoid or ReLU, acting like a "light dimmer switch").
  • Forward propagation passes signals forward; backward propagation adjusts the weights to cut the total error (e.g. MSE). The final weights are the network's parameters.
  • Deep neural nets: ≥ 2 hidden layers, often more than 20. Shallow = one hidden layer.
  • Reinforcement learning: an agent learns by trial and error (often against itself) to maximise reward over time.

07Exam traps

⚠️
  • Continuous target (e.g. a return) → supervised regression, not classification. Clustering has no target.
  • LASSO with λ = 0 is not regularisation: it's OLS. Pruning a CART is regularisation.
  • PCA is dimension reduction, not clustering. k-means partitions into a fixed k.
  • "Group 10,000 stocks into 20 clusters": 20 is the hyperparameter k. Portfolio size and universe size are not.
  • CART's advantages over KNN: no k to set, no distance metric needed, and a visual explanation.
  • Low bias + high variance = overfit. Both an overfitting penalty and cross-validation reduce it.
  • Ensembles beat the best single model on accuracy and stability.
  • Deep learning needs ≥ 2 hidden layers (not "≥ 20"). The summation operator weights inputs; the activation function transforms them.
  • k-fold cross-validation is not suitable for time-series data.
