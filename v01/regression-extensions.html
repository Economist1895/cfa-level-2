Extensions of Multiple Regression

In 30 seconds

  • High-leverage point = extreme X (flag with leverage hii​). Outlier = extreme Y (flag with the studentized residual).
  • Influential = removing it materially changes the regression. Extreme points aren't automatically influential.
  • Dummies: n categories → n−1 dummies. The omitted one is the base, captured by the intercept. Intercept dummy shifts the line; slope dummy tilts it.
  • Logistic regression for a binary Y: model the log odds, estimate by MLE, assess fit with the LR test and log-likelihood.

01Influential observations

F1

Leverage rule of thumb (extreme X)

hii​>3(nk+1​)

hii​ is between 0 and 1: the distance of observation i's X from the mean of X. Leverages sum to k+1, so the average is (k+1)/n. The flag is 3× the average.

F2

Studentized deleted residual (extreme Y)

ti∗​=se∗​ei∗​​=MSE(i)​(1−hii​)​ei​​
ei∗​
Yi​ minus the prediction from the model estimated without observation i
MSE(i)​
MSE of the model that deletes observation i

∣ti∗​∣>3 → outlier. ∣ti∗​∣> critical t with n−k−2 df → potentially influential.

  • An extreme point lying close to the line is harmless. A point far from the line tilts it, changing slopes and fit.
  • Remedies: data error → correct or discard and re-estimate; or winsorise. A valid point may signal an omitted variable or a violated assumption.

02Dummy variables

  • A dummy is 1 if the condition holds and 0 otherwise (sector, before/after an event, size threshold).
  • n categories → n−1 dummies. Using n would make the dummies sum to the intercept's column of 1s, an exact linear relation, so the model can't be estimated (the dummy trap).
  • Dummy coefficients are measured relative to the base (omitted) category.
F3

Intercept dummy

Y=b0​+d0​D+b1​X+ε

D = 1 → intercept b0​+d0​. The line shifts parallel by d0​.

F4

Slope dummy (interaction term)

Y=b0​+b1​X+d1​(D×X)+ε

D = 1 → slope b1​+d1​. Same intercept, different slope.

F5

Both

D=0:D=1:​Y=b0​+b1​XY=(b0​+d0​)+(b1​+d1​)X​
💡
Seasonality with month dummies: 11 dummies (Jan–Nov). The intercept = December (base month) mean. Test each dummy with a t-test, and the group with the F-test.

03Logistic regression (qualitative Y)

  • A linear probability model (OLS on a 0/1 Y) can predict P > 1 or < 0, and wrongly assumes a constant marginal effect.
  • Logit gives an S-shaped (sigmoid) curve bounded by 0 and 1. Errors follow a logistic distribution (like a normal but with fatter tails).
F6

Odds & log odds (logit)

odds=1−PP​ln(1−PP​)=b0​+b1​X1​+⋯+bk​Xk​​

P = 0.75 → odds 3 (3 to 1).

F7

Probability from the fitted model

P=1+e−(b0​+b1​X1​+⋯+bk​Xk​)1​

Plug in the X's (e.g. the means for the "average" observation). Classify as 1 if P exceeds the chosen threshold.

Interpretation

  • Slope = change in the log odds per unit change in Xj​, holding the other X's constant. It is not the change in probability.
  • Intercept = log odds of the event (Y = 1) when all X's = 0.
  • Marginal effect on P is not constant: largest near P = 0.5, tiny near 0 or 1. Compute it as P(Xˉ with Xj​+1)−P(Xˉ).
  • Coefficients estimated by maximum likelihood (binomial likelihood), not least squares. Significance tests on coefficients work like OLS (z-stat, p-value).
F8

Likelihood ratio test

LR=−2(LLR​−LLU​)∼χq2​
LLR​,LLU​
log-likelihoods of the restricted and unrestricted models
q
number of restrictions

The logit analogue of the joint F-test. H0​: the restricted (smaller) model is adequate. Works best in large samples. LL-Null = the intercept-only model.

  • Log-likelihood is always negative: higher (closer to 0) = better fit. It is only meaningful when comparing models with the same Y.
  • No true R². Pseudo-R² can compare only different specifications of the same model on the same data.

04Exam traps

⚠️
  • Leverage: compute 3(k+1)/n (e.g. 3 × 3/96 = 0.094). Don't just pick the single highest hii​ or an arbitrary cut-off.
  • Studentized residuals: compare the absolute value with the critical t. Large negative values count too. Df = n−k−2.
  • Month dummies: intercept = the base month return, not the average of the dummy coefficients.
  • Seasonality test: negative adjusted R², insignificant F and all t's insignificant → seasonality highly unlikely.
  • Logit is chosen because Y is binary. Dummy X's have nothing to do with it.
  • Logit slope = Δlog odds (not odds, not probability), holding the other X's constant.
  • Higher (less negative) log-likelihood = better: −450.4 beats −451.7.
  • "Using only significant variables": include the intercept plus the significant slopes, then compare P with the stated threshold.
  • To predict a fall in P most reliably, pick the significant coefficient with the right sign, not an insignificant one.
